# Projet Java SE – Élection législative de Nepalus

Projet de Java SE du Master 2 Data Sciences de l'INP-HB Yamoussoukro (Prof. Bi Tra GOORE) :
simulation du traitement informatique d'une élection législative, avec une interface JavaFX.

Groupe : **DAH BEBE SAMUEL**, **BROU KOUAKOU CEPHAS**, **DJE KOFFI EUDES**.

| Dossier | Contenu |
|---|---|
| [`election-nepalus/`](election-nepalus/) | Application (Maven, Java 17+, JavaFX 21) : sources, tests, diagrammes de classes et captures d'écran. Instructions de lancement dans son [README](election-nepalus/README.md). |
| [`rapport/`](rapport/) | Rapport de projet (Word et PDF). |

Lancement rapide, depuis le dossier `election-nepalus` :

```powershell
.\mvnw.cmd clean package
java -jar target\election-nepalus.jar
```
